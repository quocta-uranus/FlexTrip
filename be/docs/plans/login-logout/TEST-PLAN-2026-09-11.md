## Automated Coverage

| Case | Expected result |
|---|---|
| Verified active account logs in | Returns access and refresh tokens with current database roles |
| Unknown email or wrong password | Returns the same HTTP 401 message |
| Refresh token rotation | New token works and replaced token returns HTTP 401 |
| Logout with current token | Returns HTTP 204, clears stored token and blocks refresh |
| Invalid, replaced or revoked logout token | Returns the same HTTP 204 response without changing another token |
| Suspended account logout | Current refresh token is still revoked |
| Missing, wrong type or extra body field | Validation returns HTTP 400 |
