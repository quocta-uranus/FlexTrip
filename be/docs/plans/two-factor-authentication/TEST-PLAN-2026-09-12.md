# Test Plan: AUTH-04 Two-Factor Authentication

**Date:** 2026-09-12
**Branch:** feat/two-factor-authentication
**Domain:** src/modules/auth
**Risk level:** High

## Coverage

- Setup requires a valid access token and eligible current role.
- Secret is encrypted and recovery codes are stored as hashes.
- Login returns only a short-lived challenge when 2FA is enabled.
- TOTP and recovery-code login paths issue normal JWTs.
- Recovery code replay, invalid code and invalid challenge are rejected.
- Disable removes 2FA data and revokes the current refresh token.
- Full authentication regression suite, build and lint must pass.
